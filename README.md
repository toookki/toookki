  * Agente en Telegram con búsqueda híbrida de productos (keywords + embeddings semánticos + filtros estructurados) y arquitectura RAG para minimizar alucinaciones.

* **Forecasting Jerárquico de Demanda Retail** &nbsp;|&nbsp; [ Ver en GitHub ↗ ](https://github.com/toookki/ACME-Forecast)
  * Sistema de pronóstico a 90 días para 144 SKUs con estructura jerárquica (Región / Canal / Categoría / SKU), logrando un **4.91% de WAPE** a nivel empresa mediante XGBoost y funciones de pérdida asimétricas.
  * *Tech:* Python, XGBoost, Hierarchical Forecast, Pandas.

* **Sistema de Segmentación y Medición Autónoma - IDIEM** &nbsp;|&nbsp; [ Ver en GitHub ↗ ](https://github.com/toookki/IDIEM-Concrete-Slump-Test)

  * *Tech:* PyTorch, OpenCV, Computer Vision, Linear Regression.
